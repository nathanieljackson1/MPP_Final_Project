This is the code repository For my MPP final project. It is a GPU implemented parameter sweep EMI filter simulation, with several optimized kernel versions.

NOTE:
Files with the comment "DOUBLE implementation" are the double precision version files of the GPU project. "_double" appended onto the end of each file, remove before running.

Files with the comment "SINGLE implementation" are the single float precision version files of the GPU project. "_single" appended onto the end of each file, remove before running.

Files with the comment "CPU Baseline" are the cpu C++ version files that acts as the conventional baseline. "_CPU" appended onto the end of each file, remove before running.
