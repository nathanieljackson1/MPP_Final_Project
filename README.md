This is the code repository For my MPP final project. It is a GPU implemented parameter sweep EMI filter simulation, with several optimized kernel versions.

NOTE:
Files in the "Double_Precision" folder are the double precision version files of the GPU project.

Files in the "Single_Precision" folder are the single float precision version files of the GPU project.

Files in the "CPU_Baseline" folder are the CPU baseline version files of the GPU project.
